# ouillane-analyse

Analyse fondamentale hebdomadaire lue par l'onglet « Fondamental » du journal OuillaneDESK.

- `analysis.json` : analyse de la semaine en cours (format version 1), réécrite le samedi à 08h35 et complétée chaque soir de semaine après les annonces.
- `archives/AAAA-MM-JJ.json` : copie de chaque semaine (date du lundi).

Aucune donnée de compte ni de trade dans ce dépôt.
